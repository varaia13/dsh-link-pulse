# dsh-link-pulse

[![npm](https://img.shields.io/npm/v/dsh-link-pulse?color=blue)](https://www.npmjs.com/package/dsh-link-pulse)
[![License](https://img.shields.io/badge/license-Apache--2.0-green.svg)](./LICENSE)

DSH-плагин наблюдения цепочки моделей и задержки вышестоящего шлюза: отображает сетевую задержку round-trip в реальном времени, одним взглядом показывая состояние канала шлюза и цепочки моделей.

### Ключевые возможности

- **Наблюдение текущей модели диалога**: боковая панель постоянно и динамически отслеживает состояние выбранной модели сессии, в реальном времени показывая имя соответствующего шлюза и задержку (например, `● CPA · Gemini 3.7 · 126ms`).
- **Keep-Alive: реальное измерение 1-RTT**: измерение задержки HTTP-ответа через постоянный TLS-канал, точно отражающее физическую сетевую задержку; нулевое потребление токенов.
- **Динамическое обнаружение провайдеров**: автоматически читает конфигурации шлюзов из `~/.dsh/settings.yaml` (CPA, OpenCode, DeepSeek и т.д.), без жёсткого кодирования.
- **Мини-панель и панель измерений**: наведение на иконку даёт карточку предпросмотра модели; поддерживается просмотр общего ранжирования задержек шлюзов и их состояния.

### Установка и использование

**Установка в один шаг:**

```bash
dsh plugin --profile web add dsh-link-pulse
```

**Установка через репозиторий GitHub:**

```bash
dsh plugin --profile web add github.com/varaia13/dsh-link-pulse
```

**Быстрое использование:**

1. После установки запустите (или перезапустите) интерфейс DSH Web (`dsh web`).
2. В боковой панели - постоянное отображение текущей задержки; при наведении быстро сравнивается задержка шлюза текущей модели.

**Удаление:**

```bash
dsh plugin --profile web remove dsh-link-pulse
```
